# 🚌 Bus Ticket Booking Website UI/UX

A modern, clean, and fully responsive **Bus Ticket Booking Website UI/UX** design built from scratch using **HTML5** and **CSS3**. 

This project focuses on creating an intuitive, user-friendly, and visually appealing interface for online bus ticket booking. Developed as one of my very first web development projects, it served as a practical way to master frontend layout design, responsive media queries, and core UI/UX principles.

## 📖 About The Project

This project showcases a complete landing page and booking interface designed to mimic a real-world transport application. The layout guides users seamlessly from discovering destinations to searching for routes and filling out booking details.

### The Primary Goal:
* Practice semantic HTML structural design.
* Master CSS layout techniques (Flexbox, Grid, and Positioning).
* Implement mobile-first or desktop-down responsive media queries.
* Understand how to visually structure pricing, forms, and navigation cards.

---

## ✨ Features

* **Modern & Clean UI:** A professional color palette and typography choice suited for an enterprise travel application.
* **Fully Responsive Layout:** Smooth transitions and shifting layouts that adjust perfectly across desktops, tablets, and smartphones.
* **Route Search Component:** An elegant interface for selecting departure points, destinations, and travel dates.
* **Booking Form UI:** Clean input fields, dropdowns, and button states designed for low user friction.
* **Icon Integration:** Utilizes Font Awesome icons to add context to forms and navigation links.

---

## 🛠️ Built With

* **HTML5:** For semantic page architecture.
* **CSS3:** For custom styling, layout grid systems, and responsiveness.
* **Google Fonts:** For clean, modern typography.
* **Font Awesome:** For crisp vector UI icons.
* **Git & GitHub:** For version control and deployment via GitHub Pages.

### 🤖 AI Tools Used
To accelerate my learning and optimize my development workflow, I utilized AI tools for:
* Brainstorming UI/UX design inspiration and color palette harmonies.
* Generating realistic placeholder text and marketing content.
* Debugging tricky layout issues and recommending layout optimization.

*Note: AI tools were used purely as a learning assistant. The entirety of the HTML structure, CSS rules, and responsive design architecture were manually coded, customized, and tested by me.*
